= Dotfiles
:toc: left
:icons: font

Personal dotfiles managed with https://www.chezmoi.io/[chezmoi], covering shell (zsh), git, neovim, ghostty, tmux, starship, television, sesh, mise, GPG, and AI tooling (Claude Code, OpenCode).
Secrets are GPG-encrypted and stored in the repository — a YubiKey is required to decrypt them on apply.

== Setup a new environment

=== Prerequisites

[source,bash]
----
# macOS
brew install chezmoi pinentry-mac

# Linux (Arch/Omarchy)
sudo pacman -S chezmoi pinentry
----

=== Apply dotfiles

[source,bash]
----
chezmoi init --apply git@github.com:alecharp/.dotfiles.git
----

=== GPG & YubiKey

The YubiKey must be plugged in during `chezmoi apply` to decrypt secrets.
On a fresh machine, import the card stubs first:

[source,bash]
----
gpg --card-status
gpgconf --kill gpg-agent && gpgconf --launch gpg-agent
----


=== Re-authenticate tools

These tools write their own credential files and are excluded from the repository:

[source,bash]
----
gh auth login
docker login          # if using Docker
gcloud auth login     # if using Google Cloud
----

== Tools not managed by these dotfiles

These tools are used in aliases, configs, or shell init, but their installation is not managed here.
Install them before applying:

[source,bash]
----
# macOS — core shell tools
brew install bat eza ripgrep fzf zoxide delta lf

# Terminal & session management
brew install ghostty tmux sesh television starship hunk

# Git & dev tools
brew install neovim gh

# Runtimes — managed by mise after apply
# mise will install Java (temurin-25), Maven 3.9, and Node LTS
# automatically from ~/.config/mise/config.toml
----

Plugin managers (zinit, tpm) are bootstrapped automatically via `.chezmoiexternal.toml` on first `chezmoi apply`.
